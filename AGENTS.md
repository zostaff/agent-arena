# Repository language

All repository content must be in English, including documentation, specifications,
roadmap entries, code comments, UI text and commit or pull request descriptions.

Keep Russian-language notes and user-facing local reports outside this repository,
in `/Users/admin/agent-arena-local/`. Do not add or link those local reports in
repository files. Conversation replies may follow the user's preferred language.

# Product name

The public product name is **DEGEN VILLAGE**. `agent-arena` is the repository
and package identifier only. Use DEGEN VILLAGE in product copy, announcements,
roadmap headings and artwork. Preserve existing repository URLs and code paths.

# Visual identity

All new game surfaces, NFT artwork, avatar pickers and release tools must follow
the existing DEGEN VILLAGE style: warm black and olive surfaces, lime accents,
cream text, subtle panel borders and JetBrains Mono typography. Reuse the shared
CSS tokens in `src/ui/styles.css` and palette in `src/ui/theme.ts`. Keep character
variants within this palette; do not introduce a separate visual identity for
new features. NFT residents follow the owner's black/lime mascot-logo reference:
bold silhouettes, expressive faces and circular frames. Original artwork must not contain third-party logos or wordmarks.
