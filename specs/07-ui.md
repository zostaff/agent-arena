# 07 — UI (`src/ui/`)

React, SVG only, no canvas, no chart library.

## Projection (`iso.ts`)

```
screenX = (gx - gy) * 31
screenY = (gx + gy) * 15.5
depth   = gx + gy
```

`sortByDepth()` is a stable painter's-algorithm sort over every renderable —
buildings, terminal, agents — in one pass. Ties keep insertion order.

## Buildings (`Building.tsx`)

Three faces (top, left, right), each with its own `linearGradient` in `<defs>`.
Window strips on both walls, glowing and pulsing while an agent trains inside.
A diamond roof element, an antenna with a blinking tip and an expanding pulse
ring, and five level pips along the base. Unbuilt buildings render at 45%
opacity. A running job shows a progress bar and the ticks remaining.

## Terminal (`Terminal.tsx`)

A raised platform (base diamond, skirt, lifted top), a beam of light going up
whose opacity tracks how many agents are working it, and three counter-rotating
elliptical rings at different heights, speeds and colours. Labelled
`TERMINAL` / `RH·CHAIN DEX`.

## Agents (`AgentSprite.tsx`)

A circle with a specular highlight and an eye slit, over an elliptical ground
shadow that **shrinks as the agent hops** — the only cue that sells the hop.
A rotating dashed selection ring on the ground. A BUY/SELL badge above the
head. Custom FORGE builds carry a dashed outer ring.

## Notifications

`+1 SPD`, `+0.31 ETH`, `LEVEL 4` — SVG text with a CSS `float-up` keyframe
(fade in, rise 34px, fade out over 2.4s). Colour-coded: accent for stats, green
or red for P&L, amber for levels.

## HUD (`Hud.tsx`)

Glassmorphism cards (`backdrop-filter: blur(16px)`, lime hairline border) for
**TREASURY**, **NET P&L**, **ROSTER**, **RANK**. Active boosts are timer cards
top-right with a countdown bar and the boost shop underneath. Rival standings
(top 3 villages) sit above the speed controls bottom-right. The left column
holds the agent inspector — stat bars over the compiled config they produce —
and the building panel with BUILD / UPGRADE / RUSH.

The inspector also carries **REWIRE**: the three house buttons, priced at 60
coins, disabled on the current house and while a position is open (the note
underneath says which of the two it is). The `provider` and `model` rows above
it change on the next tick, because the config is recompiled from the agent,
not cached.

## DEX overlay (`Dex.tsx`)

Hand-rolled SVG candlesticks (60 candles, auto-scaled, wick + body), a
depth-shaded order book, open positions with live unrealised P&L, and the trade
tape with each fill's reason.

## Palette

```
background  #1C180D   accent  #CCFF00
SCOUT #22d3ee   SNIPER #a3e635   WHALE #fbbf24   ARB #e879f9   CUSTOM #CCFF00
```

JetBrains Mono throughout, loaded from Google Fonts with a monospace fallback
stack.

## Runtime

The browser runs **sim mode** — `SimMarket` + `heuristicBrain`, seeded 42,
stepped from `requestAnimationFrame` at 1x–8x with a pause. Live mode is
`MODE=live npm run live` from node, so the API key stays on the machine instead
of in a bundle.
